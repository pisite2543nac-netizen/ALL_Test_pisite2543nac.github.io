## วิธีใช้บนเครื่อง
เปิด `index.html` ในเบราว์เซอร์ หรือใช้ Live Server ใน VS Code เพื่อการทำงานที่เสถียรกว่า

## วิธีติดตั้งบน GitHub Pages
1. สร้าง Repository ใหม่บน GitHub
2. อัปโหลดไฟล์ทั้งหมดในโฟลเดอร์นี้ไว้ที่ root ของ repository
3. ไปที่ **Settings → Pages**
4. Source เลือก **Deploy from a branch**
5. Branch เลือก `main` และโฟลเดอร์ `/ (root)` จากนั้น Save
6. รอ GitHub สร้าง URL แล้วเปิด `index.html` เป็นหน้าผู้เข้าสอบ และ `admin.html` เป็นหน้า Admin

## ข้อจำกัดด้านความปลอดภัยและฐานข้อมูล
GitHub Pages เป็น static hosting จึงไม่มี server/database กลางในตัว เวอร์ชันนี้ใช้ `localStorage` ของเบราว์เซอร์ ดังนั้น:
- คะแนนจากนักเรียนหลายเครื่องจะ **ไม่รวมมาอยู่ที่ Admin เครื่องเดียวโดยอัตโนมัติ**
- Admin สามารถ Export/Import JSON เพื่อสำรองหรือย้ายข้อมูลระหว่างเครื่องได้
- การล็อกอิน Admin ฝั่ง static ทำได้เพียงระดับ UI; แม้ไฟล์นี้เก็บค่า credential เป็น SHA-256 hash แต่ผู้ที่ควบคุม source/client สามารถแก้โค้ดหรือข้ามการตรวจได้
- หากต้องการใช้งานจริงหลายเครื่องและต้องการปกปิดคะแนน/รหัส Admin อย่างปลอดภัย ควรเชื่อม Firebase, Supabase หรือ backend ของวิทยาลัย แล้วเก็บ credential และการตรวจคะแนนไว้ฝั่ง server
