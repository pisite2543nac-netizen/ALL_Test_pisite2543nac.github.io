NANGRONG EXAM — ข้อสอบสำเร็จรูป + ลงทะเบียนเรียลไทม์ + ผลสอบเฉพาะหลังส่ง

สิ่งที่เปลี่ยนในเวอร์ชันนี้
1. ข้อสอบสำเร็จรูปอยู่ในเว็บแล้ว 550 ข้อ / 11 วิชา / วิชาละ 50 ข้อ
2. ไม่ต้องเลือกไฟล์ JSON เพื่อนำเข้าข้อสอบเอง
3. เมื่อ Admin Login ครั้งแรก ระบบจะตรวจ Firestore และเติมข้อสอบมาตรฐานที่ขาดให้อัตโนมัติ
4. หน้า Student สามารถใช้คลังข้อสอบที่มากับเว็บเป็น fallback ได้ทันที แม้ Firestore ยังเติมไม่ครบ
5. Admin ยังเพิ่ม / แก้ไข / ลบข้อสอบได้ตามเดิม
6. มีปุ่ม “คืนค่าข้อสอบสำเร็จรูป 550 ข้อ” หากต้องการรีเซ็ตคลัง
7. นักศึกษากด “ลงทะเบียนและเลือกวิชา” แล้ว ชื่อถูกบันทึกใน studentCheckins ทันที
8. หน้า Admin แท็บ “ผู้ลงทะเบียน” รับข้อมูลแบบเรียลไทม์
9. สถานะผู้ลงทะเบียน: ลงทะเบียนแล้ว -> กำลังสอบ -> ส่งข้อสอบแล้ว / ยุติการสอบ
10. คะแนนเกิดและแสดงในหน้า Admin เฉพาะเมื่อมี submission หลังส่งข้อสอบแล้ว
11. นักศึกษายังเลือก “รับเฉลยหลัง 30 นาที” หรือ “ไม่รับเฉลย” ได้
12. หน้า Student ไม่แสดงคะแนน

ขั้นตอนติดตั้ง
- แตก ZIP แล้วอัปโหลดวางทับไฟล์ทั้งหมดใน root ของ GitHub Repository
- รอ GitHub Pages deployment สำเร็จ
- นำ firestore.rules ไป Firebase > Firestore Database > Rules > Publish
- เข้า Admin 1 ครั้ง ระบบจะเติมข้อสอบมาตรฐานลง Firestore อัตโนมัติ
- หลังจากนั้น Admin สามารถเพิ่ม/แก้ไข/ลบข้อสอบได้ตามปกติ
