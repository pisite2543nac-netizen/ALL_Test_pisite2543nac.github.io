📝

⏱️
เวลาสอบ 75 นาที เมื่อกด “เริ่มทำข้อสอบ” เวลาจะเริ่มนับทันที
🔀
การสุ่มข้อสอบ ระบบสุ่มลำดับคำถามและลำดับตัวเลือกของแต่ละคน
✅
การส่งข้อสอบ ตรวจคำตอบให้ครบก่อนส่ง เมื่อส่งแล้วไม่สามารถกลับมาแก้คำตอบได้
🚨
สำคัญมาก: แต่ละ User มีสิทธิ์สอบรายวิชาละ 2 ครั้งเท่านั้น

เมื่อกด “เริ่มทำข้อสอบ” จะนับเป็นการใช้สิทธิ์ 1 ครั้งทันที และถ้าการสอบถูกยุติจากการทำผิดกติกา รอบนั้นจะถูกนับเป็น 1 ครั้งเช่นกัน เมื่อใช้ครบ 2 ครั้ง ระบบจะยุติสิทธิ์สอบรายวิชานั้นทันที และต้องติดต่อ Admin เพื่อขอปลดล็อกสิทธิ์สอบใหม่

ข้อปฏิบัติระหว่างสอบ

  1. ทำข้อสอบด้วยตนเอง และไม่เปิดเว็บไซต์หรือโปรแกรมอื่นระหว่างสอบ
  2. ห้ามเปลี่ยน Tab / Window, ออกจาก Fullscreen, Copy, Cut, Paste หรือคลิกขวาระหว่างสอบ
  3. ระบบจะบันทึกพฤติกรรมต้องสงสัย หากเกิน 2 ครั้ง ระบบจะยุติการสอบทันที และรอบที่ถูกยุติจะนับเป็นสิทธิ์สอบ 1 ครั้ง
  4. ต้องอยู่ใน Fullscreen ตลอดเวลาสอบ ห้ามพับ/ย่อหน้าต่าง, สลับโปรแกรม, เปิด View Source หรือ Developer Tools ระหว่างสอบ การออกจาก Fullscreen หรือหน้าเว็บจะถูกบันทึกเป็นพฤติกรรมต้องสงสัย
  5. ห้าม Refresh หรือปิดหน้าเว็บระหว่างทำข้อสอบ เพราะอาจทำให้การสอบสะดุดหรือข้อมูลคำตอบสูญหาย
  6. หากหมดเวลา ระบบสามารถส่งคำตอบที่มีอยู่โดยอัตโนมัติ
  7. คะแนนสอบจะไม่แสดงในหน้าของนักศึกษา คะแนนจะแสดงในหน้า Admin เท่านั้น
