ผู้จัดทำ: นายพิสิษฐ์ หุนตระนี ครูพิเศษสอน
11 รายวิชา วิชาละ 50 ข้อ คะแนนเต็ม 20 คะแนน เวลา 75 นาที

คำชี้แจงการสอบ

  1. กรอกข้อมูลผู้เข้าสอบให้ครบถ้วนและตรงกับข้อมูลจริง ก่อนดำเนินการเลือกวิชา
  2. หลังลงทะเบียน ระบบจะแสดงรายวิชาทั้งหมด แต่ละวิชามีช่องกรอก Code แยกจากกัน
  3. กรอก Code ของรายวิชาที่ต้องการสอบให้ถูกต้อง แล้วระบบจะเข้าสู่ข้อสอบวิชานั้น
  4. แต่ละรายวิชามีข้อสอบ 50 ข้อ ระบบสุ่มลำดับข้อและตำแหน่งตัวเลือก ก–ง สำหรับผู้เข้าสอบแต่ละคน
  5. คะแนนเต็ม 20 คะแนน ระบบไม่แสดงคะแนนในหน้าผู้เข้าสอบ ผู้ดูคะแนนได้เฉพาะ Admin
  6. ผู้เข้าสอบสามารถเลือก “รับเฉลย” หรือ “ไม่รับเฉลย” ได้ หากเลือกรับเฉลย ระบบจะเปิดเฉลยพร้อมเหตุผลรายข้อหลังส่งข้อสอบครบ 30 นาที
  7. มีเวลาทำข้อสอบ 1 ชั่วโมง 15 นาที เมื่อหมดเวลาระบบจะส่งคำตอบที่มีอยู่โดยอัตโนมัติ
  8. การส่งด้วยตนเองต้องตอบครบทุกข้อก่อน ปุ่มส่งข้อสอบจึงจะเปิดใช้งาน
  9. ระบบใช้โหมดเต็มจอและตรวจการสลับแท็บ ออกจากเต็มจอ การคัดลอก วาง และคลิกขวาระหว่างสอบ
  10. หากตรวจพบพฤติกรรมต้องสงสัยเกิน 3 ครั้ง ระบบจะยุติการสอบและบันทึกสถานะ
  11. เมื่อส่งข้อสอบแล้วจะไม่สามารถย้อนกลับมาแก้ไขคำตอบของรอบนั้นได้
